# Annotation Format

The evaluation script expects manual annotations as a CSV with the following columns:

- `start_time_s`: float, start time in seconds
- `end_time_s`: float, end time in seconds
- `label`: one of `OPEN`, `CLOSED`

Example:

```csv
start_time_s,end_time_s,label
0.00,1.20,OPEN
1.20,1.55,CLOSED
1.55,3.00,OPEN
```

Predictions are generated by running the app with `--csv` and are expected to contain:

- `time_s`
- `ear`
- `state`

The evaluator converts prediction frames to `OPEN`/`CLOSED` by treating `CLOSED` as closed and everything else as open (configurable in code).
